# Introduction

On monte un peu le niveau ! Dans le chapitre des
[Listes](https://tp.girlscancode.fr/python/listes/), tu as vu comment stocker
dans une seule variable plusieurs données, comme des nombres ou du
texte. Et si nous stockions des listes... dans une liste ?

Dans ce chapitre, nous allons découvrir les **matrices**, qui sont des sortes de
**grille**.

Les matrices sont très utiles pour :
* Représenter des jeux en deux dimensions, qu’il s’agisse de mondes de jeux
(les anciens *The Legend of Zelda* et *Pokémon*, *Super Mario Bros*, *Stardew
Valley*) ou de jeux basés directement sur une grille (*Pacman*, *Tetris*,
*Sudoku*, *Échecs*, *Puissance 4*).
* Représenter une image, qui est une grille de pixels.
* Organiser des données sous forme de tableau, comme une feuille de calcul
(Excel, LibreOffice Calc) ou un emploi du temps, avec les lignes pour les
heures et les colonnes pour les jours.
